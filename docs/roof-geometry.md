# 屋根形状と高さの共通仕様

数値表示、3D、制御データは `engine/roof.ts` を参照する。3Dメッシュは `src/roof.ts` で生成する。

- `Box.roof` はボリュームの屋根区分（gable/flat）。外観を適用した実形状は `roofSpec.kind`（gable/hip/flat）。
- ホワイト／ブラックの切妻：壁の短辺 × 0.28。軒の出 0.5m。
- 和風の寄棟：壁の短辺 × 0.30。軒の出 0.75m。
- 棟は長辺方向。正方形はu方向。軒を含めた幅ではなく、壁の短辺を高さの基準にする（従来の描画形状を維持）。
- 陸屋根：パラペット0.50m＋笠木0.08m。最高点は壁の上端＋0.58m。
- 壁の上端：`(baseFloor + floors) * floorHeight`。複数ボックスは最高点の最大値を採用し、最後に0.1mへ丸める。建物がなければ0m。
- `computePlans({ exteriorStyle })` は外観込みの高さを返す。外観だけの変更は `applyExteriorStyle(plan, style)` で再配置せず更新する。
- 制御パッケージは外観、実際の屋根区分、寸法仕様、同じ高さを記録する。各画像・GLBを作る直前に同じ案と外観を選び直す。

## 確認

`npm test` は3外観、切妻／寄棟／陸屋根、長辺の向き、正方形、狭幅／大きい建物、baseFloor、複数棟、L字／コの字／段状、空の案、反復外観切替、制御仕様を検査する。Three.jsの実メッシュ最高点とエンジン値を照合する。

## 範囲外

これは参考イメージの幾何形状と数値を一致させる修正であり、法令適合性の判定ではない。現行の道路斜線・低層地域の階数制限は簡易計算のまま。屋根・軒・パラペットを含めた法規チェック、接合部や内部重複の解消は別途検討する。

実端末の外観比較、スマートフォンのfps／メモリ計測、WebGLでの視覚確認は別途必要。メッシュの数値テストを見た目や性能の合格とは扱わない。
