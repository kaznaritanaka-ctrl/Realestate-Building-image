# 個人情報を持たない全体設計

- 状態：**採用**（2026-11-06）。オーナー方針「セキュリティに自信がないので、顧客情報は極力持たない（収益面のマイナスは許容）」に基づく
- 置き換え：site-design.md のメール通知・contacts/consents テーブルは廃止

## 1. 原則
1. **個人を特定できる情報を受け取らない・保存しない**（メールアドレス・氏名・電話・住所の文字列・アカウント）
2. 計算はできるだけ**利用者のブラウザ内**で行う（ボリュームエンジン・3D・制御画像の作成）
3. サーバーに残すのは「誰のものか分からない」データだけ。それも**期限付き**で消す
4. 送客（アフィリエイト）は、利用者が**広告主のページで直接**申し込む。こちらは情報を中継しない
5. 漏れても困らない構成にする（漏えい時の最悪の内容＝匿名の敷地形状と生成画像）

## 2. データの置き場所
| データ | 置き場所 | 保持 | 個人情報か |
|---|---|---|---|
| 入力途中・結果の一覧（「最近の結果」） | 利用者のブラウザ（localStorage） | 利用者が消すまで | ―（サーバーに来ない） |
| 住所の検索語 | ブラウザ → 国土地理院へ直接 | 保存しない | ―（サーバーに来ない） |
| 地点の座標（用途地域・周辺建物の照会） | Worker が国・PLATEAUのAPIへ中継 | タイル単位のキャッシュのみ（1〜7日） | ×（地図タイル単位。誰の問い合わせか分からない） |
| 生成ジョブ（仕様JSON・制御画像） | D1・R2 | 生成後30日で削除 | ×（住所文字列なし・連絡先なし） |
| 生成結果の画像 | R2（非公開） | 30日で削除／利用者がいつでも削除 | × |
| 利用状況イベント | D1 | 1年 | ×（ブラウザごとの一時ID、位置なし、面積は区分のみ） |
| 広告クリック | D1 | 1年 | ×（一時IDと枠名のみ） |
| お問い合わせ | 運営者のメール（システム外） | ― | ○（システムには入れない） |

**持たないもの**：メールアドレス、アカウント・パスワード、Cookieによる追跡、IPアドレスの独自記録、住所の文字列、アップロード画像。

## 3. メールなしで「後から結果を見る」仕組み
1. 「写真品質の画像を作る」を押すと、ブラウザが制御パッケージ（白模型・深度・線画・マスク・仕様）を作って送信する。ボット対策は Turnstile
2. サーバーは推測できない**結果トークン**（128bit）を発行し、結果ページ `/r/{トークン}` を返す
   - D1 には**トークンのハッシュ**だけを保存する（DBが漏れても結果ページのURLは分からない）
3. 進捗ページは数十秒ごとに状態を確認する。待ち時間の目安を表示する
4. 閉じても戻れるように：
   - ブラウザの「最近の結果」に自動で残す（その端末だけ）
   - 「リンクをコピー」「共有」（端末の共有機能で自分のLINE・メモ・メールへ送る。**こちらはアドレスを見ない**）
   - タブを開いている間は、ブラウザの通知で完成を知らせる（サーバーからのプッシュは使わない）
5. 結果ページから「この結果を削除」ができる。30日で自動削除

※生成をOpenAI等のAPIにする場合は1分前後で終わるため、その場で待つ体験にできる。自宅GPU（10〜15分）でも上記で成立する

## 4. 全体構成
```
[利用者のブラウザ]
  住所検索 ──────────────▶ 国土地理院（直接）
  地図・敷地描画・ボリュームエンジン・3D・制御画像作成（すべてブラウザ内）
  「最近の結果」（localStorage）
      │ 座標だけ                         │ 制御パッケージ（匿名）
      ▼                                 ▼
[Cloudflare Worker]  ── 照会の中継とキャッシュ ──▶ 不動産情報ライブラリ／PLATEAU／国土地理院
  /api/zoning /api/site-info /api/plateau /api/buildings（保存しない）
  /api/jobs（作成・状態）  /r/{token}（結果）  /api/event（匿名の利用状況）  /go/{slot}（広告）
      │
  D1：jobs（トークンのハッシュ・状態・期限）、events、affiliate_clicks
  R2：制御パッケージ・生成画像（非公開、30日）
      ▲ pull（外向きのみ）
[生成：自宅PCのComfyUI runner ／ または画像API]
```

## 5. セキュリティ（守る範囲を小さくする）
- **認証が必要なのは運営者だけ**：管理画面は Cloudflare Access、runner は専用トークン。利用者のログインは作らない
- **公開APIの制限**：ジョブ作成は Turnstile＋1日の上限（全体・1端末）。照会系はキャッシュと入力値の範囲チェック
- **秘密情報**は Workers のシークレットのみ（APIキー・runnerトークン）。ブラウザ・リポジトリに置かない
- **自宅PC**は受信ポートを開けない。ComfyUI は 127.0.0.1 のみ。入力は自分で作った画像と決まった選択肢だけ
- **CSP** で外部スクリプトを禁止（現状どおり）
- **削除の自動化**：毎日の cron で期限切れのジョブ・画像を削除

## 6. 収益面の影響と補い方
| 失うもの | 補い方 |
|---|---|
| メールでの再訪・お知らせ配信 | 結果ページに広告枠（PR）を置く／「最近の結果」で再訪／X・note・LINE公式など**相手のプラットフォーム側**でのフォロー（データは各社が保持） |
| 見込み客リストの販売・直接送客 | もともとやらない方針（アフィリエイトのみ） |
| ユーザーごとの分析 | 匿名イベントでファネル（どこで離脱するか）は測れる |

## 7. 法務面
- 個人情報を取得しないため、プライバシーポリシーは「取得しない」ことを中心に簡潔にできる（アクセス解析・Cookie不使用・外部サービスへの座標照会・広告のCookieを記載）
- 特定電子メール法の対象外（メールを送らない）
- 生成画像・入力は匿名データとして扱うが、念のため「削除できる」「30日で消える」を明記
