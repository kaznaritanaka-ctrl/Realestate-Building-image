# 土地情報・A4横3ページレポートの設計（2026-11-07）

## 出力フォーマット
- **1枚目：** 土地概要＋建築イメージA/B/Cの4分割。
- **2枚目：** 都市計画・建築関連の参考情報。ユーザー入力・公的データ・簡易計算を分離し、未確認事項を記載。
- **3枚目：** 災害・地形関連の参考情報、自治体・専門家への確認事項。
- A4横・3ページ固定。ブラウザの「PDFで保存／印刷」でユーザー自身が保存。運営サーバーはPDFを受け取らない。
- 建築の可否・法令適合・見積の確定には利用しない。「該当データなし」「未取得」「未判定」を区別する。
- 結果は敷地中心付近の**点照会**が基本で、敷地全体に規制がかからないと保証できない。敷地ポリゴンとの交差判定は将来課題。

## 今回増やした取得対象
| 情報 | API | ライセンス・注意 |
|---|---|---|
| 立地適正化計画 | 不動産情報ライブラリ XKT003 | 国交省の掲載コンテンツ一覧で商用利用〇（区域内は個別確認） |
| 高潮浸水想定 | 不動産情報ライブラリ XKT027 | 商用利用〇。地図表示の整備時期と異なる場合あり |
| 災害履歴 | 不動産情報ライブラリ XST001 | 商用利用〇。調査地域・収録された事例に限る。点・線は参照点から150m以内を含む |
| 参照地点の標高 | 国土地理院標高API（試験提供） | 約10m単位に丸めた座標を1日キャッシュ。高低差・造成要否・地盤強度は分からない |

**要確認／非掲載**：XKT028（津波）、XKT016（災害危険区域）、XKT021（地すべり）、XKT022（急傾斜地）は、一部データに非商用制限あり。自治体別許諾チェック・利用条件の確認前に一括取得しない。

**重要な既存データの修正**：XKT029（土砂災害警戒区域）にも一部非商用制限があるため、今回のブランチでは保守的にAPI照会を停止し、「提供保留（商用利用条件の確認中）」と表示する。自治体別のデータ許諾・ホワイトリスト管理を整備してから段階再開する。これは「区域外」の意味ではない。

出典・仕様：
- [不動産情報ライブラリ API仕様一覧](https://www.reinfolib.mlit.go.jp/help/apiManual/)
- [掲載コンテンツの出典・商用利用可否](https://www.reinfolib.mlit.go.jp/help/contents/)
- [国土地理院 標高API（試験提供）](https://cyberjapandata.gsi.go.jp/development/elevation_s.html)

## 実装ファイル
- `worker/site-info.ts`：追加レイヤー・ライセンス保留
- `worker/index.ts`：標高取得（丸め＆キャッシュ）、配信
- `src/siteinfo.ts`：結果画面の表示・エラーの区別
- `src/report.ts`：A4横・3ページ用の独立HTML生成
- `src/app.ts`：3案のブラウザ内キャプチャ＋取得待ち＋印刷ビュー
- `site/assets/report.css`：3ページ印刷用CSS

## 検証項目（マージ・公開前）
1. npm ci → npm test → npm run build → npx tsc --noEmit
2. Chrome/Edgeの印刷プレビューで**3ページ**、A4横、背景グラフィック表示。Windows/iPhoneの「PDFで保存」でページが追加されないこと。
3. 通常の矩形敷地と旗竿地、条件が厳しい市街化調整区域、サンプル敷地、データ未取得の地域で表示確認。
4. GSI標高APIの応答失敗・未取得時もPDFが作れ、誤って「標高0m」を表示しない。
5. URLで入力データを共有した場合のプライバシー説明、PDF中の参照地点（座標）の扱いを確認。
6. 追加APIでWorkersの上流リクエスト数が増えるため、Issue #3〜#5のレート／予算制限を公開前に解決。
7. 元データの基準日や利用条件は、必要に応じて原典側にリンクし、最新の自治体資料での確認を促す。
